  <action>
    Define `bootstrap_week_ci(panel: pd.DataFrame, iters: int, seed: int) -> pd.DataFrame`. FIRST, validate input:
    `if iters <= 0: raise ValueError(f"bootstrap-iters must be a positive integer, got {iters}")` — this guard runs
    before any array allocation (mitigates T-6-01, ASVS V5; a zero/negative size would otherwise produce a malformed
    or empty result). Then implement the verified vectorized sum/count-matrix algorithm from RESEARCH.md Pattern 2:

    1. `years = np.sort(panel["iso_year"].unique())`; `n_years = len(years)`; map each iso_year to a 0-based index.
    2. Build `sum_mat` and `cnt_mat` of shape `(n_years, 52)` by grouping `log_ret_bps` on `(year_idx, iso_week)`
       and filling `sum` and `count` at `[year_idx, week-1]` (week is 1..52, so index `week-1`).
    3. `rng = np.random.default_rng(seed)` (the modern Generator API — do NOT use the legacy global `np.random.seed`).
       `draw = rng.integers(0, n_years, size=(iters, n_years))`.
    4. `resampled_sum = sum_mat[draw].sum(axis=1)` and `resampled_cnt = cnt_mat[draw].sum(axis=1)` (both `(iters, 52)`).
       `resampled_week_mean = resampled_sum / resampled_cnt`.
    5. `baseline_mean = resampled_sum.sum(axis=1) / resampled_cnt.sum(axis=1)` — the baseline is recomputed per
       iteration from the SAME resampled draw (Pitfall 4), giving shape `(iters,)`.
    6. `delta = resampled_week_mean - baseline_mean[:, None]` → `(iters, 52)`.
    7. `ci_low, ci_high = np.percentile(delta, [2.5, 97.5], axis=0)` (percentile bootstrap — no BCa/normal
       approximation, keeping "no tunable test statistic" per SEAS-09).
    8. `significant = (ci_low > 0) | (ci_high < 0)`.

    Return a DataFrame with a `week` column of the weeks actually present in the panel (1..52 that have observations),
    aligned with their `ci_low_bps`, `ci_high_bps`, and `significant` values, sorted by week. Guard against
    divide-by-zero for a week with zero resampled count in some iteration (a week with no observations should not
    appear in the output at all; use `np.errstate`/mask empty-week columns so an all-empty week never yields a
    spurious CI). Keep the function pure (no I/O, no wall-clock).
  </action>
