## Angular Column Specification

### Column Headers (D-06)

Insert after the `Conf` column, before `Entry`. Exact header text:

| Column key | Header text | Sort support | Class |
|------------|-------------|--------------|-------|
| `industry_group` | `Industry` | Yes — `sort('industry_group')` | `industry-group-cell` on `<td>` |
| `industry_momentum` | `Mom` | Yes — `sort('industry_momentum')` | `.mom-pos` or `.mom-neg` on `<td>` |
| `industry_above_50ma` | `Trend` | Yes — `sort('industry_above_50ma')` | none |
| `industry_rank_pct` | `Rank%` | Yes — `sort('industry_rank_pct')` | `.num` on `<th>` and `<td>` |

**Rationale for `Trend` over `50MA` or `↑↓`:** A text word reads cleanly in the header without ambiguity with sort indicators (which also use ↑↓ via `sortIcon()`). `Trend` is self-explanatory to a trader (is this industry in an uptrend?).

### Cell Display Rules (D-07, D-09, D-10)

```
industry_group:    s.industry_group ?? '—'
                   class="industry-group-cell" [title]="s.industry_group ?? ''"

industry_momentum: s.industry_momentum == null ? '—' : (s.industry_momentum >= 0 ? '+' : '') + s.industry_momentum.toFixed(1) + '%'
                   [class.mom-pos]="s.industry_momentum != null && s.industry_momentum > 0"
                   [class.mom-neg]="s.industry_momentum != null && s.industry_momentum < 0"

industry_above_50ma: s.industry_above_50ma == null ? '—' : s.industry_above_50ma === 1 ? '↑' : '↓'
                   NOTE: use === 1 strict equality, NOT truthy check. 0 means "below 50MA" — a valid state.

industry_rank_pct: s.industry_rank_pct == null ? '—' : 'Top ' + Math.round(s.industry_rank_pct) + '%'
                   class="num"
```

### TypeScript Interface Extension (D-01)

Add to `Signal` interface in `api.service.ts` after `notes: string | null`:

```typescript

industry_momentum: number | null;
industry_above_50ma: number | null;

```

All 4 use `| null` (not `| undefined`) — consistent with all existing nullable fields in the interface.

### Sort Logic

The existing `sorted` getter uses `(a as any)[this.sortCol] ?? 0` — this handles all 4 new numeric/string columns without modification. The `sort()` method only needs the column key strings to be passed from the new `(click)="sort('industry_group')"` etc. bindings in the template. No changes to `candidates.component.ts` sort logic are required.

## CLI Display Specification

### Column Names and Order (D-05)

Full display column order after preprocessing:

```
ticker | strategy | score | confidence | Industry | Mom | Trend | Rank% | close | suggested_stop | suggested_target | risk_reward
```

### Format Preprocessing (D-02, D-03, D-04)

Apply before `df[display_cols].to_string(index=False)` in `_print_scan_results()`:

```python
# Create formatted display columns
df['Industry'] = df['industry_group'].fillna('—')
df['Mom']      = df['industry_momentum'].apply(
    lambda v: f'{v:+.1f}%' if v is not None and not pd.isna(v) else '—'
)
df['Trend']    = df['industry_above_50ma'].apply(
    lambda v: '↑' if v == 1 else ('↓' if v == 0 else '—')
)
df['Rank%']    = df['industry_rank_pct'].apply(
    lambda v: f'Top {v:.0f}%' if v is not None and not pd.isna(v) else '—'
)
```

**UTF-8 safety:** `scan.py` calls `sys.stdout.reconfigure(encoding='utf-8')` at line 22 — ↑ and ↓ are safe to emit.

**NULL contract:** Any NULL/NaN value in any of the 4 source columns renders as `—` (em dash U+2014). Never emit `0`, `0.0`, `None`, or empty string for a NULL industry field.

## NULL Handling Contract

This phase has a strict NULL contract that spans both surfaces:

| Field | NULL source | CLI output | Angular output |
|-------|-------------|------------|----------------|
| `industry_group` | ETF not mapped or yfinance miss | `—` | `—` (via `?? '—'`) |
| `industry_momentum` | ETF < 21 bars or unmapped | `—` | `—` (via null check) |
| `industry_above_50ma` | ETF < 50 bars or unmapped | `—` | `—` (via `=== 1 ? '↑' : '↓'` guard) |
| `industry_rank_pct` | Universe < 2 industries or unmapped | `—` | `—` (via null check) |

`industry_above_50ma === 0` (integer zero) is NOT null — it must render `↓`, not `—`. This is the critical edge case. The Angular template must use `s.industry_above_50ma == null ? '—' : s.industry_above_50ma === 1 ? '↑' : '↓'`.
