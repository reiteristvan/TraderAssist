<objective>
Deliver the complete Python backend vertical slice for the pre-registered Winner/Loser characteristic analysis. After this plan, running `python scan.py backtest` produces a `## Winner/Loser Characteristic Analysis (Pre-registered)` section in report.md and a `wl_analysis` key in report.json / `backtest_reports.metrics_json` — a full end-to-end capability the owner can observe from the CLI without any web changes.

Purpose: Surface which entry-time metrics genuinely discriminate winners from losers, with hard guards (pre-registered feature list, per-bucket suppression, total-sample abort) against the cherry-picking failure mode that produced the ADX and volume-contraction gate reversals.

Output: Extended Signal dataclass, metric capture in the backtest loop, the analysis + render functions in report.py, and full test coverage for WLA-01 through WLA-06.
</objective>
