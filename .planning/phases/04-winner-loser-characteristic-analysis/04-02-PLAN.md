<objective>
Deliver the web vertical slice that surfaces the Phase 4 W/L analysis to the user. After this plan, opening a backtest run in the Angular UI shows a `W/L Analysis — {Strategy}` card per strategy with the pre-registered 6-metric winners/losers/delta table, an abort warning when the run had too few trades, and a per-strategy suppression warning when a bucket is under-sampled — exactly per the locked 04-UI-SPEC.md contract.

Purpose: Make the pre-registered discriminant analysis visible where the owner already reviews backtests, closing the CLI→web parity gap for Phase 4.

Output: API exposure of wl_analysis, TypeScript interfaces, component getter + format helpers, the template cards, and component tests.
</objective>

<phase_goal>
**As a** swing trader reviewing backtest results in the web UI, **I want to** see the pre-registered winner/loser metric breakdown per strategy on the run detail page, **so that** I can read which entry-time characteristics discriminate winners from losers without dropping to the CLI.

(Continuation of the Plan 04-01 phase goal — this slice adds the web surface for the analysis computed in 04-01.)
</phase_goal>
