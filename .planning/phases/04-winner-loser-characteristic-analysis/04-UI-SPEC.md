**Delta column color:** The delta column (winners_median − losers_median) is rendered in the default body color (`#e0e0e0`) with no color-coding. ## Pre-registered Feature Set

The W/L feature list is a fixed constant committed to `scanner/report.py` source code before any backtest run results are viewed. This is the anti-cherry-picking guard required by WLA-02.

```python
# Pre-registered W/L feature set — defined in code before results are viewed (WLA-02 guard)
WL_FEATURES = [
    'RSI at entry',
    'RVOL',
    'Pullback depth %',
    'ATR multiple',
    'Industry momentum',
    'Pct to 52w high',
]
```

This constant is the sole authoritative list. The analysis function must iterate over `WL_FEATURES` in order — no dynamic feature selection.

## Angular Component Specification

### Placement in `backtests.component.html`

Insert two new `.card` blocks after the existing "Target distance — by ATR" card and before the "Trade list" card. One card per strategy. Both cards are wrapped in a guard on `wlAnalysis`.

### Guard Logic

| Condition | Render |
|-----------|--------|
| `wlAnalysis == null` | Nothing (analysis not present in this run) |
| `wlAnalysis.aborted === true` | Single `.warning-box` with abort copy |
| `wlAnalysis.aborted === false` | Per-strategy cards from `wlAnalysis.strategies` |
| Strategy `suppressed === true` | `.warning-box` inside card, no table |
| Strategy `suppressed === false` | Table with 6 metric rows |

### Template Skeleton

```html
<!-- W/L analysis — abort warning -->
<div class="warning-box" *ngIf="wlAnalysis?.aborted">
  {{ wlAnalysis!.abort_reason }}
</div>

<!-- W/L analysis — per-strategy cards -->
<ng-container *ngIf="wlAnalysis && !wlAnalysis.aborted">
  <div class="card" *ngFor="let s of wlAnalysis.strategies">
    <h2>W/L Analysis — {{ s.strategy | titlecase }}</h2>
    <p class="section-desc">
      Pre-registered entry-time metrics (6). Feature list defined in
      <code>report.py</code> source code before results were viewed.
    </p>

    <!-- suppression warning -->
    <div class="warning-box" *ngIf="s.suppressed">
      {{ s.suppression_reason }}
    </div>

    <!-- comparison table -->
    <table *ngIf="!s.suppressed">
      <thead>
        <tr>
          <th>Metric</th>
          <th class="num">Winners (n={{ s.winner_n }})</th>
          <th class="num">Losers (n={{ s.loser_n }})</th>
          <th class="num">Delta</th>
        </tr>
      </thead>
      <tbody>
        <tr *ngFor="let row of s.rows">
          <td>{{ row.metric }}</td>
          <td class="num">{{ fmtWlValue(row.metric, row.winners_median) }}</td>
          <td class="num">{{ fmtWlValue(row.metric, row.losers_median) }}</td>
          <td class="num">{{ fmtWlDelta(row.metric, row.delta) }}</td>
        </tr>
      </tbody>
    </table>
  </div>
</ng-container>
```

### Component Class Additions (`backtests.component.ts`)

```typescript
get wlAnalysis(): WlAnalysis | null {
  return this.selectedRun?.wl_analysis ?? null;
}

fmtWlValue(metric: string, value: number | null): string {
  if (value == null) return '—';
  switch (metric) {
    case 'RSI at entry':      return value.toFixed(1);
    case 'RVOL':              return value.toFixed(2) + 'x';
    case 'Pullback depth %':  return (value >= 0 ? '+' : '') + value.toFixed(1) + '%';
    case 'ATR multiple':      return value.toFixed(2);
    case 'Industry momentum': return (value >= 0 ? '+' : '') + value.toFixed(1) + '%';
    case 'Pct to 52w high':   return value.toFixed(1) + '%';
    default:                  return value.toFixed(2);
  }
}

fmtWlDelta(metric: string, delta: number | null): string {
  if (delta == null) return '—';
  const sign = delta >= 0 ? '+' : '';
  switch (metric) {
    case 'RSI at entry':      return sign + delta.toFixed(1);
    case 'RVOL':              return sign + delta.toFixed(2);
    case 'Pullback depth %':  return sign + delta.toFixed(1) + '%';
    case 'ATR multiple':      return sign + delta.toFixed(2);
    case 'Industry momentum': return sign + delta.toFixed(1) + '%';
    case 'Pct to 52w high':   return sign + delta.toFixed(1) + '%';
    default:                  return sign + delta.toFixed(2);
  }
}
```

Import addition to component imports line:

## Sample-Size Gate Rules

These rules are implementation requirements, expressed here as visual contracts:

| Condition | Visual Contract |
|-----------|----------------|
| `total_qualified < 200` | Abort: show single warning (CLI and web), render no strategy tables |
| `winner_n < 50` OR `loser_n < 50` | Suppress: show per-strategy warning, render no metric rows |
| Both buckets >= 50 and total >= 200 | Render full 6-row metric table |
| Strategy not present in run (e.g. "both" run has pullback only) | Omit that strategy's card/section entirely |

**Suppression copy (web):** `Suppressed — fewer than 50 trades in winner or loser bucket (winners: {n}, losers: {n}).`

**Abort copy (web):** `Insufficient data — fewer than 200 qualified trades (n={n}). W/L analysis suppressed.`

Both copies are stored in `suppression_reason` and `abort_reason` in the JSON so the Angular component only needs to render `s.suppression_reason` and `wlAnalysis.abort_reason` — no copy hard-coded in the template.
