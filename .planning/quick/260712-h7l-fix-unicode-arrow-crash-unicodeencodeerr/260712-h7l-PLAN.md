<objective>
Fix the UnicodeEncodeError crash found by Phase 7 verification (07-VERIFICATION.md): the `--output`/`--csv` confirmation prints in `seasonality_by_week.py` and `scan.py` use a right-arrow character that the default cp1252 stream encoding on this project's real Windows environment cannot encode, causing the CLI to crash with exit code 1 immediately after the CSV write already succeeded. Replace it with an ASCII-safe equivalent in both files, and add a regression test that exercises the print through a genuine stream encoding (not pytest's capsys, which is encoding-blind and is why this bug shipped unnoticed through 319 passing tests).

Purpose: Un-block Phase 7 (SEAS-13 / cli-output-reporting) verification — the CSV-export success criterion is not met while the process crashes instead of returning 0.
Output: Two one-line fixes, one updated test assertion, one new subprocess-based regression test, one new test helper script.
</objective>
