<objective>
Create `scanner/seasonality.py`: the data-loading pipeline for the Weekly Seasonality Analyzer. It
validates the requested sector name, resolves a universe file to a ticker list, filters that list to the
sector via the `sector_store` cache, validates each ticker has ≥2 years of cached OHLCV history, and
returns a clean handoff object of `{ticker: DataFrame}` plus a skip report (D-04). It holds ALL Phase 5
logic; the root CLI (Plan 03) stays thin.

Purpose: Delivers SEAS-01 (case-insensitive sector filter), SEAS-02 (invalid-sector error), SEAS-03
(reuse get_history), SEAS-04 (2-year skip+log), SEAS-05 (corrupt/missing cache skip+log).
Output: `scanner/seasonality.py` with the pipeline functions + a `SectorDataset` handoff, and
`tests/test_seasonality.py`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arg (`--sector`, `--universe`, `--years`) → pipeline | user-controlled strings drive sector matching and file-path selection |
| universe name → filesystem path | `--universe` selects which universe file is read |
| yfinance (via sector_store/get_history) → in-memory frames | external data flows into the analysis set |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03 | Tampering | universe_path | high | mitigate | `--universe` is mapped through an explicit 4-entry whitelist dict to a fixed path; the raw arg is never interpolated into a Path, blocking `../` traversal. Unknown values raise ValueError. |
| T-05-04 | Denial of Service | resolve_sector_universe first-run fetch storm | low | accept | A first run against sp500/all makes up to ~500/~1500 sequential yfinance `info` calls — an accepted one-time cost per D-07, identical to the existing OHLCV cache warm-up via `scan.py refresh`. |
| T-05-05 | Tampering | validate_history OHLCV cache read | high | mitigate | A missing/corrupt ticker cache surfaces as `get_history` returning None; validate_history records it as a skip and the batch continues (SEAS-05) rather than trusting or crashing on malformed data. |
| T-05-06 | Denial of Service | validate_sector loop over unresolved tickers | low | accept | Per-ticker get_sector failures are caught, logged, and skipped; no single bad ticker can abort the batch (SKIP-not-fail, D-03). |
| T-05-SC | Tampering | package installs | low | accept | No new package-manager installs — pandas and the existing scanner deps are already vendored. No legitimacy gate required. |
</threat_model>
