<objective>
Extend `scanner/seasonality.py` with the first two computation stages of Phase 6: pool every admitted
ticker's daily log returns into one ISO-week/ISO-year-tagged panel (`compute_log_returns`), then compute
the observed per-week statistics (`week_observed_stats`) — mean/median/std daily return in bps, n_obs,
n_years — plus each week's delta vs. the pooled full-sample baseline mean. Also add the `SeasonalityResult`
dataclass shell and the numpy import that later plans build on.

Purpose: Delivers SEAS-06 (per-week mean/median/std bps, n_obs, n_years, week-53 merged into 52) and
SEAS-07 (delta vs. full-sample baseline). These are the honest point estimates the bootstrap CI (Plan 02)
and synthetic verification (Plan 03) are built on top of.
Output: New functions in `scanner/seasonality.py` (`compute_log_returns`, `week_observed_stats`, the
`SeasonalityResult` dataclass) and new unit tests in `tests/test_seasonality.py`.
</objective>
