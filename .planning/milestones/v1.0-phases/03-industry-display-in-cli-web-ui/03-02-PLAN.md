<objective>
Deliver the web-UI half of IND-07: a trader viewing the Angular Candidates page sees each
signal's industry group name, 20-day momentum (color-coded), 50-day-MA trend arrow, and rank
percentile as four new table columns — per locked decisions D-01, D-06..D-10 and the approved
03-UI-SPEC. The API already returns these columns via `SELECT *`; only the TypeScript type
contract and the component/template/styles need extending (no SQL, no API change).

Purpose: Surface Phase 2's stored industry momentum in the primary signal-browsing surface so
the trader can weigh industry strength against score/confidence at a glance.
Output: Extended Signal interface, two formatter methods, four table columns, two color
classes + one truncation class, and spec coverage.

This is a complete vertical slice: after this plan a real user can open the Candidates page
and read industry momentum in the table — end to end from DB through API to rendered cell.
